# নেদায়ে ইসলাম মহিলা ফাদ্বিল মাদ্রাসা — Roll Assignment App (নেটিভ)

Kotlin + Jetpack Compose দিয়ে লেখা নেটিভ Android অ্যাপ। HTML ডেমোর সাথে ডিজাইন/ফ্লো মিলিয়ে
বানানো হয়েছে: আপলোড → (দরকার হলে) কলাম মিলানো → সারাংশ → রোল এন্ট্রি → এক্সপোর্ট।

## যা যা বাস্তবে কাজ করে
- .xlsx ফাইল থেকে সত্যিকারের ইমপোর্ট (কোনো Apache POI না — নিজস্ব হালকা .xlsx রিডার,
  কারণ POI Android-এ প্রায়ই সমস্যা করে)
- নাম/পিতা/মাতা কলাম স্বয়ংক্রিয় শনাক্তকরণ, না মিললে ম্যানুয়াল কলাম-মিলানো স্ক্রিন
- রোল এন্ট্রি: সার্চ, ফিল্টার (সব/বাকি/সমস্যা), ডুপ্লিকেট ও ভুল-সংখ্যা শনাক্তকরণ, ফাঁকা
  ঘরে সাজেস্ট করা পরবর্তী রোল, Undo
- ডিভাইসেই অটো-সেভ (JSON ফাইল হিসেবে) — অ্যাপ বন্ধ করে আবার খুললেও কাজ হারাবে না,
  একই ফাইল আবার ইমপোর্ট করলে আগের রোলগুলো ফিরে আসবে
- যেকোনো সময় Export — সবার রোল দেওয়া বাধ্যতামূলক না
- Android হার্ডওয়্যার ব্যাক বাটন স্ক্রিন-বাই-স্ক্রিন কাজ করে

## APK বানাবেন যেভাবে (GitHub দিয়ে)
1. GitHub-এ একটা নতুন **private** repository বানান।
2. এই পুরো ফোল্ডারটা (এই README সহ) রিপোতে push করুন — ফোল্ডার স্ট্রাকচার অক্ষুণ্ণ রাখবেন,
   বিশেষ করে `.github/workflows/build-apk.yml` ঠিক জায়গায় থাকতে হবে।
3. রিপোর **Actions** ট্যাবে যান। push করার পর build এমনিতেই শুরু হয়ে যাবে (না হলে
   "Run workflow" বাটনে চাপুন)।
4. বিল্ড শেষ হতে (৫-১০ মিনিট) অপেক্ষা করুন — সবুজ টিক আসলে বুঝবেন সফল হয়েছে।
5. সেই রানের পেজে নিচে **Artifacts** অংশে `madrasa-roll-apk` নামে একটা zip পাবেন,
   ডাউনলোড করে extract করলে `app-debug.apk` পাবেন।
6. ফোনে পাঠিয়ে ইনস্টল করুন (প্রথমবার "Install from unknown sources" অনুমতি দিতে হতে পারে)।

এই APK-টা "debug" সাইন করা — নিজে ব্যবহারের জন্য সম্পূর্ণ ঠিক আছে, শুধু Google Play-তে
আপলোড করা যাবে না (সেটার জন্য release সাইনিং লাগবে, দরকার হলে বলবেন)।

## জানা সীমাবদ্ধতা (build হওয়ার পর টেস্ট করে দেখা দরকার)
- ইমপোর্ট শুধু ফাইলের **প্রথম শিট** পড়ে (মূল অ্যাপের মতোই ধরে নেওয়া হয়েছে, একটা ফাইলে
  একটা ক্লাসের তালিকা)
- এটা প্রথম বিল্ড — প্রথমবার Gradle build-এ যদি কোনো এরর আসে, সেই লগ কপি করে দিলে
  আমি ঠিক করে দেব। Android SDK/Gradle এই চ্যাটে নেই বলে আমি নিজে কম্পাইল করে
  আগে থেকে টেস্ট করতে পারিনি।
